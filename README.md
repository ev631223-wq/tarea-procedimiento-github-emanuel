 Guía Rápida de Capacitación  Control de Versiones

Bienvenido a la sección de capacitación sobre el uso del flujo de trabajo en GitHub mediante la interfaz web.

 Objetivos del Módulo
* Comprender la importancia de trabajar con ramas (*branches*) independientes para cada nueva tarea[cite: 8].
* Aprender a documentar de forma clara utilizando Markdown.
* Vincular correctamente los problemas (*Issues*) con las solicitudes de extracción (*Pull Requests*).

 Pasos del Procedimiento Web
1. **Identificar la tarea:** Revisar el Issue asignado en el repositorio.
2. **Crear la rama:** Trabajar siempre en una rama de característicaso función en lugar de la rama principal (`main` o `principal`)[cite: 8].
3. Documentar y Guardar:** Realizar los cambios necesarios en el archivo `README.md` y confirmar los cambios (*Commit*)
4. Solicitar Integración:** Abrir el *Pull Request* asociado para revisión y posterior fusión (*Merge*).

> Nota: Este repositorio sirve como evidencia práctica del dominio de los procedimientos básicos de colaboración en equipo sin utilizar la línea de comandos
